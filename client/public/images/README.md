# Images for PawCruz Veterinary Clinic

Every image the app uses is in this folder. They are **real free photos from [Unsplash](https://unsplash.com)**,
cropped to the size each spot needs. The Unsplash License lets you use them for free (including in school and
commercial projects); credit isn't required, but it's listed below as good practice.

If a file is ever missing or fails to load, the `ImageWithFallback` component shows a light-blue gradient with
a paw icon instead, so nothing breaks. Pets themselves use species icons (dog, cat, rabbit, bird…), so they need no photos.

## Where each image is used

| File | Used on | Size |
| --- | --- | --- |
| `hero.jpg` | Home hero | 1200×1290 |
| `clinic-interior.jpg` | About page, Login/Register panel | 1200×900 |
| `team.jpg` | About page | 1200×900 |
| `vet-1.jpg`, `vet-2.jpg` | Vet cards, vet profile, booking, admin (vet-1 = Dr. Neil Norman A. Cruz, vet-2 = Dr. Redmond Lopez) — stock stand-ins; replace with the vets' real photos | 640×800 |
| `service-*.jpg` | Service cards (check-up, vaccination, deworming, skin, dental, surgery, laboratory, exotic) | 800×600 |
| `testimonial-1.jpg` … `testimonial-3.jpg` | Home testimonials | 320×320 |

To swap a photo, replace the file with another one of the **same name** (similar size works best; keep it under ~300 KB).
